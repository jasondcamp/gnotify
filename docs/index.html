What it does

  • Notifies you when a PR opens with a review request for you or one of your teams.
  • Badges the menubar icon with the number of PRs currently waiting on you.
  • Lists those PRs in a popover on a To Review tab. Click one to open it in the browser. Your own PRs never appear here.
  • Shows a My PRs tab: every open PR you authored in the org, marked Approved, Changes requested, Awaiting review or Draft, with who said or was asked what.
  • Alerts you when a PR you opened gets an approving review.

Both kinds of notification have a toggle in Settings. With both off, gnotify works as a plain dashboard: list and badge only.

Privacy

Your GitHub token and settings are stored only in the app's sandboxed storage, on your own Mac.

gnotify talks to the GitHub API and nothing else.

There is no gnotify server, no account and no telemetry.

Setup

  1. Launch the app and open Settings. The first launch opens it for you.
  2. Paste a GitHub token.
  3. Enter the organization to watch.
  4. Add one or more targets: usernames, or teams written as org/team-slug. "Add me" resolves the token's own user and adds it.

Token scopes

Classic PAT

Scopes repo and read:org.

Fine-grained PAT
  • Set Resource owner to the organization, not your personal account.
  • Grant Pull requests: Read on the repos to watch.
  • Grant Members: Read on the org for team queries.

A fine-grained token issued under your personal account can read the org's metadata, but every org-scoped search returns 422 The listed users and repositories cannot be searched. If the org restricts fine-grained tokens, an org owner has to approve it.
